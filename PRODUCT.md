# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js (App Router), TypeScript, Tailwind CSS v4. Local property data with a repository boundary for future CMS/API.

## Users

Real-estate firms, developers, and agencies who need a **premium portfolio website** and scalable property detail pages without building a marketplace UI.

## Product Purpose

Present properties as an editorial luxury experience: immersive photography, clear hierarchy, one reusable detail system, and a directory fed by the same structured data.

## Positioning

A template that behaves like a design-led publication backed by a property-content model—not a generic realtor theme or listing portal clone.

## Operating Context

Operators add properties by editing structured data (later: CMS). Primary visitor action is **WhatsApp enquiry** (+504 9678-4674 in the default template config).

## Capabilities and Constraints

- Multi-page marketing site plus `/properties` directory and `/properties/[slug]` detail pages
- Conditional property sections by type and available fields
- SEO metadata, sitemap, JSON-LD per property
- Image performance via `next/image`
- Contact form not included; WhatsApp is the default channel

## Brand Commitments

Template brand **Studio Estate**—replace name, copy, and imagery when customizing.

## Evidence on Hand

Sample listings use third-party placeholder photography (Unsplash). Replace with owned assets per `docs/IMAGES.md`.

## Product Principles

1. Photography and typography carry the premium feel.
2. One property-page architecture for all listings.
3. Data drives UI; never duplicate per-property pages.
4. Ship fast locally; keep a clean path to CMS.
5. Accessibility and performance are part of the luxury experience.

## Accessibility & Inclusion

Semantic HTML, keyboard focus rings, meaningful alt text, reduced-motion support.
